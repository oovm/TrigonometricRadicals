# `n = 16`

最小多项式:

$$
x^8-8 x^6+20 x^4-16 x^2+2=0
$$

伽罗瓦群:

$$
D_{16}
$$

解得:

$$
\begin{aligned}
\sin\frac{π}{16} &= \frac{\sqrt{2 - \sqrt{2}}}{2}\\
\sin\frac{3π}{16} &= \frac{\sqrt{2 + \sqrt{2}}}{2}\\
\sin\frac{5π}{16} &= \frac{\sqrt{2 + \sqrt{2}}}{2}\\
\sin\frac{7π}{16} &= \frac{\sqrt{2 - \sqrt{2}}}{2}\\
\end{aligned}
$$

以上为 \( n = 1 \) 到 \( n = 16 \) 的三角函数速查表。
